# 🌟 Antigravity RTL Patcher
### پشتیبانی هوشمند از زبان‌های راست‌چین (فارسی، عربی و عبری) در برنامه Antigravity
### Smart Right-to-Left (RTL) Support for Persian, Arabic & Hebrew in Google Antigravity

---

## 📖 معرفی / Introduction

این ابزار محیط برنامه **Google Antigravity** را به طور کامل و هوشمند برای زبان‌های راست‌چین (**فارسی**، **العربية**، **עברית**) بهینه‌سازی می‌کند. با نصب این پچ، متون پیام‌ها، پرامپت‌ها، پاسخ‌های هوش مصنوعی و اسناد به صورت خودکار راست‌چین شده و فونت زیبای **وزیرمتن (Vazirmatn)** به همراه فونت‌های عربی و عبری فعال می‌گردد.

> 🛡️ **کاملاً امن و برگشت‌پذیر:** قبل از هر تغییری، یک نسخه پشتیبان از فایل اصلی برنامه تهیه می‌شود و هر زمان مایل باشید با ۱ کلیک می‌توانید برنامه را به حالت اولیه کارخانه برگردانید.

---

## ✨ ویژگی‌های برجسته / Key Features

- **🌐 تشخیص خودکار و هوشمند جهت (Smart Bidirectional Detection):**
  - متون فارسی، عربی و عبری به صورت خودکار راست‌چین (`RTL`) و راست‌تراز می‌شوند.
  - متون انگلیسی و لاتین چپ‌چین (`LTR`) باقی می‌مانند.
- **💻 محافظت کامل از بلوک‌های کد و ترمینال (Strict LTR for Code):**
  - کدهای برنامه‌نویسی (`pre`, `code`)، مسیر فایل‌ها، لینک‌ها، بلوک‌های تفکر هوش مصنوعی (`Thinking`) و ترمینال همیشه چپ‌چین و با فونت مونو‌اسپیس استاندارد حفظ می‌شوند.
- **🎨 ویجت شناور تنظیمات در داخل برنامه (In-App Control Widget):**
  - آیکون شناور در گوشه پایین سمت راست پنجره برنامه.
  - کلید میانبر سریع **Alt + R** برای فعال/غیرفعال کردن RTL.
  - سوییچ **Force Full RTL** برای متون ترکیبی یا حساس.
  - انتخاب سریع پریست زبان (**فارسی**، **العربية**، **עברית**، **سفارشی**).
  - اسلایدر تنظیم زنده **اندازه فونت (Font Size)** و **فاصله خطوط (Line Height)**.
- **⌨️ حل مشکل کاراکتر `@` در کیبورد فارسی:**
  - امکان فعال‌سازی تبدیل خودکار کلید `Shift + 2` به کاراکتر `@` (به جای کاراکتر جداکننده هزارگان `٬`) برای منشن کردن فایل‌ها و ابزارها در چت.
- **🔤 فونت داخلی وزیرمتن (Vazirmatn Embedded):**
  - دارای فونت متغیر وزیرمتن داخل پکیج بدون نیاز به نصب فونت روی ویندوز.
- **⚙️ هماهنگی با تنظیمات ادیتور کد:**
  - تنظیم خودکار فونت و تنظیمات `settings.json` در ادیتور Antigravity IDE.

## 🚀 نحوه استفاده / Quick Start

### روش ۱: استفاده با ۱ کلیک در ویندوز (توصیه شده)
1. روی فایل **`patch.bat`** دابل کلیک کنید.
2. پچ به صورت خودکار اعمال می‌شود.
3. برنامه **Antigravity** را باز کنید و از محیط راست‌چین لذت ببرید!

*(برای بازگردانی به حالت اولیه، کافیست روی **`unpatch.bat`** دابل کلیک کنید).*

---

### روش ۲: از طریق خط فرمان (CLI / NPM)

```bash
# نصب وابستگی‌ها
npm install

# اعمال پچ راست‌چین
npm run patch

# مشاهده وضعیت برنامه و پچ
npm run status

# منوی تعاملی و گزینه‌های پیشرفته
npm start

# بازگردانی نسخه اصلی (Unpatch)
npm run unpatch
```

---

### روش ۳: با پاورشل (PowerShell)

```powershell
# اعمال پچ
.\patch.ps1

# بازگردانی به نسخه اصلی
.\unpatch.ps1
```

## 🔄 پایداری خودکار پس از آپدیت‌ها / Auto-Patch on Windows Logon

برنامه Google Antigravity مرتباً آپدیت دریافت می‌کند و پس از هر آپدیت فایل پکیج به حالت پیش‌فرض برمی‌گردد. این پروژه مجهز به سیستم **Auto-Patch** کاملاً نامرئی در ویندوز است:
- **نحوه کارکرد:** هنگام ورود به ویندوز، یک اسکریپت کاملاً بی‌صدا و پس‌زمینه اجرا می‌شود و بررسی می‌کند که آیا Antigravity آپدیت شده است یا خیر. اگر آپدیت شده و پچ پریده باشد، در کسری از ثانیه مجدداً پچ را اعمال کرده و یک اعلان کوچک (Windows Notification) نمایش می‌دهد. اگر پچ از قبل فعال باشد، فوراً بدون مصرف رم یا پردازنده خارج می‌شود.
- **فعال‌سازی ۱ کلیکی:** روی فایل **`enable_auto_patch.bat`** دابل‌کلیک کنید.
- **غیرفعال‌سازی ۱ کلیکی:** روی فایل **`disable_auto_patch.bat`** دابل‌کلیک کنید.

---

## ⌨️ کلیدهای میانبر و کنترل‌ها

| میانبر / قابلیت | عملکرد |
|---|---|
| **Alt + R** | فعال / غیرفعال‌سازی سریع حالت RTL در برنامه |
| **Shift + 2** | تایپ کاراکتر `@` در کیبورد فارسی (قابل فعال/غیرفعال‌سازی در پنل) |
| **آیکون کره‌ی زمین** | باز کردن پنل تنظیمات فونت، اندازه و فاصله‌ها در گوشه پایین پنجره |

├── run_menu.bat             # منوی کامل تعاملی
├── enable_auto_patch.bat    # فعال‌سازی پچ خودکار پس از آپدیت‌ها
├── disable_auto_patch.bat   # غیرفعال‌سازی پچ خودکار
├── github-uploader.js       # اسکریپت همگام‌سازی و آپلود خودکار روی گیت‌هاب

│   └── Vazirmatn-Variable.woff2   # فونت توکار وزیرمتن

    ├── process.js           # مدیریت پروسه‌های در حال اجرا
    ├── injector.js          # کدهای تزریقی RTL، استایل‌ها و ویجت UI

## ❓ سوالات متداول و عیب‌یابی / FAQ & Troubleshooting

### ۱. بعد از آپدیت رسمی Antigravity چه اتفاقی می‌افتد؟
با ویژگی **Auto-Patch** که فعال است، هیچ کاری لازم نیست انجام دهید! در ورود بعدی به ویندوز، پچ به‌طور خودکار بررسی و اعمال می‌شود. همچنین هر زمان بخواهید می‌توانید دستی روی `patch.bat` کلیک کنید.

### ۲. آیا پچ خودکار سرعت سیستم را کند می‌کند؟
خیر، این اسکریپت با تکنولوژی VBScript نامرئی اجرا شده و اجرای آن کمتر از ۲۰۰ میلی‌ثانیه زمان می‌برد و هیچ پنجره سیاه CMD باز نمی‌شود.

### ۳. آیا تنظیمات من بعد از بستن برنامه پاک می‌شوند؟
خیر! کلیه تنظیمات شما (فونت انتخابی، اندازه فونت، فاصله خطوط و فعال بودن RTL) در فایل `~/.antigravity-rtl.json` در پوشه کاربری ذخیره شده و با هر بار باز شدن برنامه لود می‌شوند.
